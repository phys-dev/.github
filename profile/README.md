# Физика и код

Учебные пособия по физике ускорителей, школьной физике и программированию
в научных исследованиях. Все пособия открыты, собираются автоматически
из этих репозиториев и читаются в браузере без установки чего-либо.

## Пособия

| Пособие | О чём |
|---|---|
| [Коллективные эффекты в ускорителях](https://phys-dev.github.io/collective-effects-book/) | Кильватерные поля и импедансы, неустойчивости в моделях макрочастиц, уравнение Власова. Семнадцать вопросов с выводами и расчётами |
| [Нелинейная динамика в ускорителях](https://phys-dev.github.io/nonlinear-dynamics-book/) | Параметрический резонанс, адиабатические инварианты, сдвиги бетатронных частот, эффекты встречи и ионов |
| [Электрическая прочность](https://phys-dev.github.io/electrical-strength-book/) | Пробой в вакууме, газах и твёрдых диэлектриках, мультипактор, инженерные критерии изоляции |
| [Базовая школьная физика](https://phys-dev.github.io/school-phys-book/) | Интерактивное пособие для 7–9 классов по учебнику Перышкина: модели, опыты, задачи с разбором |
| [Разработка ПО в физических исследованиях](https://phys-dev.github.io/soft-dev-book/) | Linux, Python, Git, тесты, контейнеры, производительность: как писать надёжный научный код |
| [Базовые методы ИИ в физических исследованиях](https://phys-dev.github.io/basic-ml-book/) | Регрессия, классификация, деревья, кластеризация, нейросети, с практикумом |
| [Рецепты машинного обучения](https://phys-dev.github.io/ml-recipe-book/) | Короткие тетради с примерами обучения моделей scikit-learn на встроенных датасетах |
| [Базовые алгоритмы](https://github.com/phys-dev/algo-recipe-book) | Разборы алгоритмических задач с условиями и решениями на Python и Go, восемь спринтов |
